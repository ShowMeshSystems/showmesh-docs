## Documentation status

<StatusBadge status="experimental-active" label="Current main / development" />

These docs describe the current `main` development state. Section landing pages and capability pages use explicit maturity labels where they help distinguish available, experimental, advanced, and planned behavior. Engineering specifications and architecture decisions remain authoritative in the main ShowMesh repository; this site translates verified implementation into human-facing operating guidance.

## How to read a maturity label

- **Available** means the feature is part of the current development build and documented for normal use.
- **Experimental — Active Development** means the feature exists but can still change materially.
- **Experimental — Ready for Testing** means the feature is available for deliberate testing and feedback, but is not broadly supported or stable.
- **Planned** means the page describes intended work, not an available feature.

Experimental features might not yet have been tested with the hardware used in your installation. See [Maturity and complexity](/reference/maturity/) for the complete definitions.
