## Documentation status

<StatusBadge status="experimental-active" label="Current main / development" />

These docs describe the current `main` development state. Section landing pages and capability pages use explicit maturity labels where they help distinguish available, experimental, advanced, and planned behavior. Engineering specifications and architecture decisions remain authoritative in the main ShowMesh repository; this site translates verified implementation into human-facing operating guidance.
