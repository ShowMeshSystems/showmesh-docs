# Security policy

This repository contains only public documentation. It runs no ShowMesh software and holds no credentials.

Report a security vulnerability in ShowMesh itself privately through the main repository's [private vulnerability reporting](https://github.com/ShowMeshSystems/showmesh/security/advisories/new). Do not open a public issue for it here or there. The main repository's [SECURITY.md](https://github.com/ShowMeshSystems/showmesh/blob/main/SECURITY.md) describes the current security posture and what is already known and out of scope.

If a documentation page exposes a secret, a private hostname, or guidance that would weaken a deployment, report it the same private way rather than in a public documentation issue.
